#  Orphanage Management System

## Short Description
A cross-platform mobile application built with React Native and Expo to streamline orphanage operations, including child welfare records, donations, inventory tracking, staff management, and PDF report generation.

## Folder Structure
- `screens/` — All UI screens (Login, Dashboard, Child Welfare, Donations, Inventory, Reports, etc.)
- `firebase/` — Firebase configuration, authentication, and Firestore database backend logic

## Firebase Features Used
- **Firebase Authentication:** Email/Password user sign-up, login, and role-based access control.
- **Cloud Firestore:** Real-time NoSQL database for storing and syncing child records, donation logs, and inventory data.
